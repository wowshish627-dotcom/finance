# Финансы — приложение для iPhone

Веб-приложение, которое ставится на экран «Домой» и работает как обычное: на весь экран, без интернета, данные хранятся на телефоне. Проверено под iOS 15 (iPhone 7).

## 1. Выложить в интернет (бесплатно, ~5 минут)

Приложению нужен адрес с https, иначе iPhone не сможет его установить.

**Netlify Drop** — самый простой способ:
1. Откройте на компьютере https://app.netlify.com/drop и зарегистрируйтесь (бесплатно, можно через почту).
2. Перетащите в окно **всю папку `app`**.
3. Получите адрес вида `https://что-то-там.netlify.app`. В настройках сайта (*Site configuration → Change site name*) можно сменить его на понятный.

Подойдёт и GitHub Pages — если уже есть аккаунт GitHub.

## 2. Установить на iPhone

1. Откройте полученный адрес **в Safari** (не в Chrome и не внутри Telegram).
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой) → **«На экран „Домой"»** → «Добавить».
3. Запускайте с иконки 🟩₽. Записи вносите уже в установленном приложении: у него своё хранилище, отдельное от вкладки Safari.

## Резервные копии

Всё лежит только на телефоне. Раз в пару недель: вкладка **«Ещё» → «Сохранить резервную копию»** → сохранить в «Файлы» или отправить себе в Telegram. Восстановить: «Ещё» → «Восстановить из копии».

Не удаляйте иконку с экрана «Домой» и не очищайте данные сайтов в настройках Safari — записи сотрутся.

## Обновление

Если меняете файлы, увеличьте номер версии в `sw.js` (`finance-v1` → `finance-v2`) и снова перетащите папку на Netlify. На телефоне закройте и откройте приложение — подтянется новая версия.
